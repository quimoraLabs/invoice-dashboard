# Project Terminology Glossary

---

## Terms & Abbreviations

| Term | Full Meaning | Description in Invoice Dashboard |
| :--- | :--- | :--- |
| **BaaS** | Backend as a Service | Firebase platform handling Auth & Database services. |
| **GSTIN** | Goods and Services Tax Identification Number | Legal 15-digit tax identification number used in India. |
| **Tenant** | Data Isolation Unit | Single authenticated user identified by Firebase `uid`. |
| **Line Item** | Invoice Entry Row | Single product/service record with description, quantity, price, and total. |
| **SPA** | Single Page Application | Client-side React app routed via React Router v7. |
| **HMR** | Hot Module Replacement | Instant Vite developer feedback mechanism without reloading browser state. |
| **ADR** | Architecture Decision Record | Standard format document capturing key engineering choices. |
| **PRD** | Product Requirement Document | Spec outlining product goals, target users, and feature requirements. |
